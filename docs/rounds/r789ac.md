# Round 789, lane AC: avatars in the client

Round 789 is "asset packs (.pk3) and working avatars". The user (2026-10-16): equip into the 5
avatar slots with retail's rules, avatars drawn on yourself, other players, the select screen and
the paper doll hiding what retail hides, avatar blue options in tooltips, avatar alchemy (retail's
grant window at the blacksmith; the avatar enchant is dead in retail). Lane AC is the Godot client;
lane AS the server; the wire is shared through `client/scripts/net/testdata/avatar_golden.json`.

Labels: **READ** (seen in the binary on the RE box, with the address), **MEASURED**, **INFERRED**,
**OPEN**, **OURS**. Addresses are sro_client.exe's (c:) unless named. The research this builds on
is `/root/opensro-pk3av789/AVATAR_RESEARCH.md` and `AVATAR_ALCHEMY_RESEARCH.md`; the client's
record is docs/protocol/avatar_visuals.md. Base `feat/pk3avatar789` (b8df5deb); branch
`feat/pk3avatar789-ac`.

## 3. What was READ or MEASURED this round (beyond the research)

- **The plus cut** (c:0x6720fe..0x6721ce): `find(L"+")`, minus one, and when that is above 0 the
  string is erased from there to its end -- the "(" goes, the space before it stays.
- **The grant window's count line** (c:0x8092f0): `"%s - "` with UIIT_STT_SILKMALL_HAT/_DRESS/_ATTACH
  by TypeID4, then `"%s: %d%s"` ADD_COUNT, `ref+0x534 - SOItem count`, UNIT; no item name.
- **The grant rows' number** (c:0x80a4b0..0x80a52a): `[row+0x50]` pushed as the value of
  FUN_0066a8c0, the row being the vector's pointer -- the research's column 9 (the code string at
  +4 of that pointer); with column 9 the archive's rows read STR 1, HP 150, HR 5 (MEASURED in the
  research's table), with column 8 they would read 1, 1, 6.
- **APPLY_AVATAR_SYSTEM** is defined in the archive's `config\define.txt` (MEASURED), so
  `GDR_GRANT_MAGIC_ATTRIBUTE` (ginterface.txt, 272x395, `msgbox2_window_`) frames the window.
- **The census** (`avatar_probe.gd`, MEASURED on the box archive): 1,347 of 1,355 avatar ids find
  a ConditionID-2 row by (full word, Param7) -- 13/1 520/520, 13/2 454/454, 13/3 333/341, 13/4 40/40
  -- and 0 of 26 devil's spirits has a ConditionID-1 row. 269 Service-1 rows.
- **Hair**: 36 of the first 40 men's hats with a row hide the hair by their own attachable block
  (key 0, flag 1); none lacks a block.
- **Correction to AVATAR_RESEARCH.md 6.2**: the ConditionID-2 rows for dresses with Param7 0x023F and
  0x063F have Slot 0x023E and 0x073E (MEASURED): they do not hide the helm. The code follows the
  table.
