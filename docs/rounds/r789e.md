## 3. Bugs found and fixed (each with a test)

### 3.1 The grant window's rows were hidden under its bars (client)

MEASURED (m3b, frame `26`; `QA GRANT drawn row 0 Control shown true ... label Label 'Str 1 Increase'`):
every row's label held its text and was shown, and the window drew five empty bars. The OptionList
section builds the five bars (IDs 40..44, `com_bar01_`, opaque) after the scroll manager (ID 32) whose
children the rows are, so the bars drew over the rows and took their clicks. Fix (OURS; INFERRED that
retail's rows are over its bars -- a list that cannot be seen or clicked is not retail's -- the order
itself is not READ): `GrantMagicAttributeWindow.raise_list` moves the scroll manager after the last
bar that is its sibling. Test: `avatar_tooltip_test.gd` `_test_grant_list_order`. Live: frame `27`.

### 3.2 The selected row's bar never showed (client)

MEASURED (m3c, frame `27`: row 3 selected, all five bars alike). The gil_bar02 select/deselect art
went in at child index 0 of each bar, under UiBuilder's three opaque `com_bar01_` pieces. The client
SETS the bar's texture (READ c:0x808be0 in lane RB's research), so `apply_bar` now hides the bar's own
pieces and keeps the art on top. Test: `_test_grant_list_order`'s bar checks. Live: frame `28`.

### 3.3 NPCs vanished after a teleport within the zone (client, found on the way)

MEASURED (`tprepro`): after a GM `/tp` inside Jangan the log reads `World3D: 0/3 NPC(s) placed in
97/168 from the server's spawns`, and QA_TALK found no server smith (it fell back to the offline
greeting with only "End conversation"). The server sends the zone change, the client rebuilds the zone
in one frame (`zone jangan (97/168) is built in its own frame`), the old terrain node and the NPC
holders under it are `queue_free()`d but still `is_instance_valid()` when the new cell places its NPCs,
so `_place_npc_record` skipped every one as already placed; then the old ones were freed, and the
server, whose NPC window had not moved, sent nothing again. Fix: `World3D.npc_holder_standing` -- a
holder queued for deletion, or under a node that is, does not stand. Test: `scripts/world/
npc_rezone_test.gd`. Live after the fix (`tpfixed`): `3/3 NPC(s) placed in 97/168`, `QA TALK
NPC_CH_SMITH: select 0x7045 uid 2130706555` and the server's menu.
