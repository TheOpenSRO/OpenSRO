- **Code page**: Windows-1252 on both sides (no system code page in Go or Godot). Server: the file's
  words (a character it lacks becomes `?`; Windows' best-fit is not reproduced -- MEASURED: one CJK
  character in group 4, none in group 5, of both retail copies). Client: a code's first byte decoded.

- **Default locale** ENGLISH (retail's fallback for an unknown one; the reference server.cfg has
  `LOCALE_VIETNAM`). The bare names (`VIETNAM`) are taken as well as `LOCALE_VIETNAM`.
- **Client unknown Language** -> English (CGame+0x858's constructor value was not found).
- **Edge cases retail leaves undefined** (a final DBCS lead byte reads past the terminator in
  0x6df010 / 0x6df7f0 / 0x6df850): the scan stops at the end of the name.
- **Guild byte count** on the client is the UTF-8 it sends (retail counts ANSI bytes; equal for every
  name the English group allows).
- The guild refusal's wording (OpenSRO's guild wire carries text, not the code).
- Existing characters and guilds keep their names (the user's earlier decision).
