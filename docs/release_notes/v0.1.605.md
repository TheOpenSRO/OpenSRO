v0.1.605: F opens the stall network

- F opens and closes the Stall Network window (in a town).
- Rebind it in Option > Key Map, where it is the new "Stall network" row; Default puts it back on F.
- If you had already given F to another action, it stays there and the Stall Network row starts with no key.
- The bottom menu's entry now reads "Stall network ( F )".
- Escape closes the Stall Network window.
