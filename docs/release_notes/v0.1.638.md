v0.1.638: academy matching join fixed

- Applying to an academy through Guardian Matching now asks the academy's guardian, who can accept or refuse in a "Join request sent" box.
- The applicant's joining window now says "Registration is in process." and runs 15 seconds, instead of showing party lines.
- An unanswered or refused application now says "Request has been cancelled."; an accepted one shows "Registration has been completed." to both players.
- Refusing an academy invitation no longer shows a message to either player, as in the original.
- The server now records every academy action, so academy problems can be traced.
