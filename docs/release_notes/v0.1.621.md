v0.1.621: no more getting stuck inside rocks and buildings

- Walking or riding into rocks, trees, cliffs and buildings no longer lets you slip inside them and get stuck, at any speed.
- Arrow-key and sky-click runs now stop at walls on the server too, so letting go of the key can no longer leave you inside a building.
- If your game ever places you past a wall, the server now puts you back where you really are instead of accepting it.
