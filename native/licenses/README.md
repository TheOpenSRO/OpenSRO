# Licence texts shipped in the release zips

`rust-COPYRIGHT`, `rust-LICENSE-MIT` and `rust-LICENSE-APACHE` are the Rust project's own files
at the tag of the pinned toolchain (`rust-lang/rust` 1.98.1, read 2026-10-01). The Rust standard
library is linked into `opensro_native`. `native/third_party_notice.sh` copies these files into
each zip's THIRD_PARTY_NOTICES.txt. Refresh them when RUST_TOOLCHAIN changes.
